# Memory 구조 / Stack·Heap

## 메모리 계층 구조
- 레지스터 > 캐시 > 메모리(램) > 하드디스크(저장장치)로 구성되어 있으며 속도와 용량이 반대로 작용한다. 
- 속도와 용량의 상호보완을 위해 고안한 방법(경제성)
- locality of reference(참조 지역성)에 의해서, 자주 사용하는 데이터는 프로세서와 가까이 위치시켜 속도를 향상시키는 것이다.
  - 레지스터 : CPU 내부 작은 메모리, 휘발성, 용량 적음, 속도 제일 빠름
  - 캐시 : L1, L2, L3 캐시로 이루어져 있으며, 휘발성, 용량 적음
  - 주기억장치(메모리) : RAM, 휘발성
    - HDD로부터 일정량의 데이터를 복사하여 임시 저장하며 CPU에 전달하는 역할
  - 보조기억장치(디스크) : HDD, SDD, 비휘발성, 속도 낮으나 기억용량이 많음

## 프로세스의 메모리 구조
- code(text), data, heap, stack 영역으로 구성되어 있음.
- code
  - 실행할 프로그램의 코드가 저장되며 cpu가 명령어를 코드영역에서 하나씩 가져와 처리함
- data
  - 정적 변수, 전역 변수가 저장됨.
  - 시작 시에 할당되어 프로그램 종료 시 소멸됨
  - BSS(block stated symbol) 영역 내부에는 초기화되지 않은 전역 변수가 저장되며, 초기화된 전역 변수는 data 영역의, 비휘발성 ROM에 저장된다. (경제성)
- stack
  - 지연변수, 매개변수, 리턴값등의 사용되었다가 사라지는 데이터를 저장
  - 함수 호출 시 할당, 반환 시 소멸. 컴파일(로드)시에 크기가 결정됨
- heap
  - 동적 데이터, 메모리 주소값에 의해 참고되고 사용되는 영역
  - 런타임에 크기가 결정됨
  - stack 내부에서 pointer 변수를 할당한다면 참조하는 heap 영역 임의의 공간, 크기를 할당하여 사용함.
