# 4주차 - Network

## 공통 키워드
- OSI 7 Layer/TCP-IP
네트워크 통신 과정을 계층별로 나누어 표준화한 모델.
각 계층은 하위 계층의 서비스를 이용하고, 상위 계층에 서비스를 제공한다.
1. 7계층 - 응용: 사용자 인터페이스 및 네트워크 서비스 제공.  
2. 6계층 - 표현: 데이터 암호화, 압축, 인코딩/디코딩(JPEG, MIME.. 등)  
3. 5계층 - 세션: 응용 프로그램 간의 연결 확립, 유지, 종료 관리.
4. 4계층 - 전송: 종단 간 (END - TO - END) 신뢰성 있는 데이터 전송. (TCP, UDP)  
5. 3계층 - 네트워크: 목적지까지의 최적경로 설정 및 패킷 전달(IP, ICMP, Router)
6. 2계층 - 데이터 링크: 인접 장비 간의 물리적 전송 오류 제어 및 프레임 전달  
7. 1계층 - 물리: 전기적/광학적 신호로 비트스트림 전송.  

- IP
  인터넷상에서 컴퓨터들이 서로 데이터를 주고받기 위해 사용하는 네트워크 계층의 대표적인 프로토콜.
  주요 특징
  1. 비연결성: 데이터 송신 전 연결을 설정하지 않고 패킷을 독립적으로 전송한다.
  2. 비신뢰성: 패킷이 순서대로 도착하는지, 전송 중 손실되는지 보장하지 않는다.

  IP 주소 체계
  1. IPv4: 32비트 주소 체계, 주소 고갈 문제 존재.
  2. IPv6: 128비트 주소 체계
 

- TCP/UDP
  전송 계층에서 데이터 전송 방식을 결정하는 두가지 핵심 프로토콜.
                 TCP                   UCP  
  연결방식    연결 지향적           비연결 지향적  
            (3-WAY HANDSHAKE)  
  신뢰성         높음                   낮음
  전송 속도   상대적으로 느림         매우 빠름
  제어 기능  흐름 제어, 혼잡제어,    최소한의 오류 검출(Checksum)만 제공  
                오류 제어
  주요 용도   웹 브라우징(HTTP),     실시간 스트리밍, 온라인 게임, DNS, VoIP  
             파일 전송(FTP), 이메일(SMTP)  
  
- 3-way/4-way Handshake
  TCP 연결을 설정하고 해제하는 절차  
  대화를 시작하기 전에 상대방과 나 모두 소통가능한 상태인지 확인하는 절차라고 할 수 있음.
3-way-Handshake  
  [클라이언트]                                  [서버]  
     |                                          |  
     | ----- (1) SYN: "내 말 들려?" ----------> |  
     |                                          |  
     | <---- (2) SYN+ACK: "잘 들려! ---------- |  
     |                    내 말도 들려?"        |  
     |                                          |  
     | ----- (3) ACK: "응, 잘 들려!" ---------> |  
     |                                          |  
     [ 연결 완료 (ESTABLISHED) ]          [ 연결 완료 (ESTABLISHED) ]

4-way-Handshake  
  [클라이언트]                                  [서버]  
     |                                          |  
     | ----- (1) FIN: "나 이제 끝낼게" --------> |  
     |                                          |  
     | <---- (2) ACK: "알겠어! 잠시만..." ----- | (남은 데이터 전송 중)  
     |                                          |  
     | <---- (3) FIN: "나도 전송 끝! 끊자" ---- |  
     |                                          |  
     | ----- (4) ACK: "응, 끊자!" ------------> |  
     |                                          |  
 [TIME_WAIT 대기 후 종료]                   [즉시 종료]
