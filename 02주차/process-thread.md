# Process / Thread

## Process

- 운영체제로부터 자원을 할당받는 자원의 단위
- 실행 중인 프로그램 = 프로세스
- OS 위의 모든 프로그램은 OS가 만든 프로세스 위에서 실행된다.

### 프로세스의 메모리 구조 (Code, Data, Memory)

- **code** : main 메서드를 포함한 모든 코드를 의미함
- **data** : 실행 중 저장할 수 있는 저장 공간
  - 전역 변수, 정적 변수(static), 배열 등의 데이터를 저장함
- **memory**
  - **stack** : 지역 변수, 매개변수, 리턴 변수를 저장함
  - **heap** : 동적 할당(`new()`, `malloc()`), 참조형 변수의 원본값을 저장함

## Thread

- 프로세스가 할당받은 자원을 이용하는 **실행의 단위**
- Java의 경우 메인 스레드(JVM)가 main 메서드를 실행시키며 시작됨
  - 메인 스레드는 프로세스가 실행될 때 같이 실행되며, 필요에 따라 병렬적 실행이 가능함
  - 자바는 멀티 스레드를 지원함
- 스레드 생성 시 프로세스 내의 주소 공간과 메모리 공간을 할당받음
- 경량 프로세스(LWP, light-weight process)라고 부르기도 한다.

### 싱글 스레드와 멀티 스레드

Java `main` 메서드의 스레드를 메인 스레드라고 부르는데, 이 경우가 싱글 스레드에 해당한다. JVM의 메인 스레드가 종료되면 JVM도 동시에 종료된다.

하나의 프로세스는 여러 개의 스레드를 가질 수 있으며, 프로세스 내의 자원을 공유한다.

- **장점**
  - 여러 스레드를 통해 병렬 처리하여 성능이 좋음
  - 스택을 제외한 모든 영역에서 메모리를 공유하여 자원을 효율적으로 사용 가능함
  - 응답 스레드와 작업 스레드의 분리로 비동기 처리가 가능함 (응답 시간 단축)
- **단점**
  - 동기화
    - 프로세스의 자원을 공유하며 처리하여 collision이 발생할 수 있음
  - deadlock
    - 둘 이상의 스레드가 자원을 원할 때 서로 기다리며 작업을 진행할 수 없는 상태
    - 걸리는 시간과 동작이 예측 불가능하다
