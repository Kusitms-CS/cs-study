# 2주차 - OS: Process / Thread / 동시성

## 1. 프로세스 (Process)

- 운영체제로부터 자원을 할당받는 **실행 중인 프로그램의 단위**. 디스크에 저장된 정적인 코드 덩어리인 "프로그램"과 구분된다.
- 프로세스는 독립적인 주소 공간(Code, Data, Heap, Stack)을 가지며, OS는 PCB(Process Control Block)로 프로세스 상태·레지스터 값·스케줄링 정보 등을 관리한다.
- 프로세스 상태 전이: New → Ready → Running → (Waiting) → Terminated
- 멀티프로세스는 프로세스 간 메모리가 분리되어 있어 안정성은 높지만, 프로세스 간 통신(IPC)에 파이프·소켓·공유 메모리 등 별도 비용이 든다.

## 2. 스레드 (Thread)

- 프로세스 내에서 실제로 실행되는 흐름의 단위. 하나의 프로세스는 여러 개의 스레드를 가질 수 있다(멀티스레드).
- 같은 프로세스에 속한 스레드끼리는 Code/Data/Heap 영역을 **공유**하고, Stack과 레지스터만 스레드마다 독립적으로 가진다.
- 그래서 스레드는 프로세스보다 생성 비용과 컨텍스트 전환 비용이 낮지만, 자원을 공유하기 때문에 동기화 문제(레이스 컨디션 등)가 발생할 수 있다.
- 프로세스 vs 스레드 한 줄 비교: "프로세스는 자원을 나눠 갖고 격리되어 안전하지만 무겁다 / 스레드는 자원을 공유해서 가볍지만 동기화가 필요하다."

## 3. 컨텍스트 전환 (Context Switching)

- CPU가 하나의 프로세스(또는 스레드)를 실행하다가 다른 프로세스(또는 스레드)로 전환할 때, 현재 실행 상태(레지스터, 프로그램 카운터 등)를 PCB/TCB에 저장하고 다음 실행할 대상의 상태를 복원하는 과정.
- 인터럽트, 시스템 콜, 타임 슬라이스 소진 등으로 발생.
- 오버헤드가 존재하는 이유: 캐시/TLB miss 증가, 저장·복원 자체의 CPU 사이클 소모. 스레드 간 전환이 프로세스 간 전환보다 저렴한 이유는 주소 공간(메모리 매핑 정보)을 다시 로드하지 않아도 되기 때문.

## 4. 동시성 (Concurrency) vs 병렬성 (Parallelism)

- **동시성**: 여러 작업을 번갈아 실행하며 마치 동시에 진행되는 것처럼 보이게 하는 것. 싱글 코어에서도 시분할(time-slicing)로 가능.
- **병렬성**: 여러 작업을 물리적으로 동시에(멀티코어 이상에서) 실제로 같이 실행하는 것.
- 즉 동시성은 "구조/설계"의 문제(작업을 어떻게 겹쳐서 진행할 것인가), 병렬성은 "실행"의 문제(실제로 동시에 도는가). 병렬성 없이도 동시성은 구현 가능하다.

## 5. 레이스 컨디션 (Race Condition)

- 둘 이상의 스레드/프로세스가 공유 자원에 동시에 접근하고, 그 결과가 실행 순서(타이밍)에 따라 달라지는 상황.
- 대표 예시: 두 스레드가 동시에 `count++`를 수행할 때, read-modify-write가 원자적이지 않아 값이 유실되는 경우 (Lost Update).
- 발생 조건(Critical Section 문제의 3요소): Mutual Exclusion(상호 배제) 미보장, 공유 자원 존재, 비원자적 접근.
- 해결 방법이 바로 아래의 동기화 기법.

## 6. 뮤텍스 (Mutex) / 세마포어 (Semaphore)

- **뮤텍스**: 하나의 스레드만 공유 자원(critical section)에 접근하도록 하는 **잠금(lock)** 메커니즘. Lock/Unlock 소유권이 명확해서, 잠금을 건 스레드만 해제할 수 있다. (Binary, 소유 개념 O)
- **세마포어**: 지정된 개수(N)만큼의 스레드가 동시에 자원에 접근할 수 있도록 허용하는 카운터 기반 동기화 도구. 소유 개념이 없어서 다른 스레드가 signal(release)할 수도 있다.
- 한 줄 비교: "뮤텍스는 화장실 열쇠 1개(잠근 사람만 열 수 있음), 세마포어는 좌석 N개짜리 대기실 카운터(아무나 자리를 비켜줄 수 있음)."
- 세마포어 카운트를 1로 설정하면 뮤텍스처럼 쓸 수 있지만, 소유권 개념이 없어 데드락 디버깅이 더 어렵다는 차이가 있다.
