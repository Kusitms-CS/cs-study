# 동시성 (Context Switching / 동시성·병렬성 / Race Condition / Mutex·Semaphore)

## Context Switching

참고: https://lsh2016.tistory.com/185

- 두 스레드 간의 전환 지점에서 발생하는 overhead가 존재함
- 컨텍스트 스위칭에 소모하는 시간은 매우 짧으나 스레드가 많은 경우에는 비용이 커질 수 있다.
- CPU 코어 수 + 1개 정도로 스레드를 맞추면 특정 스레드가 잠시 대기할 때 남은 스레드를 활용할 수 있다.

## 동시성 / 병렬성

참고: [동시성과 병렬성의 개념과 차이](https://velog.io/@kwontae1313/%EB%8F%99%EC%8B%9C%EC%84%B1%EA%B3%BC-%EB%B3%91%EB%A0%AC%EC%84%B1%EC%9D%98-%EA%B0%9C%EB%85%90%EA%B3%BC-%EC%B0%A8%EC%9D%B4)

- **동시성(Concurrency)** 은 하나의 시스템이 여러 작업을 동시에 처리하는 것처럼 **보이게** 하는 것이다.
  - 스레드, 코루틴, 비동기 프로그래밍
  - 실질적으로는 한 번에 하나의 작업만을 처리한다.
  - 논리적 개념
- **병렬성(Parallelism)** 은 여러 작업을 **실제로** 동시에 처리하는 것이다.
  - 멀티 코어 컴퓨터 등을 활용해 각 작업이 다른 CPU 또는 다른 CPU core에서 병렬적으로 실행된다.
  - 물리적 개념

### 동시성 vs 멀티태스킹

- **멀티태스킹**은 하나의 시스템에서 여러 개의 작업(task)을 동시에 실행하는 것을 말한다. 운영체제는 이를 위해 여러 개의 프로세스 또는 스레드를 생성해 동시에 실행한다. 하나의 CPU를 사용해 여러 작업을 처리하므로 시스템 자원을 효율적으로 활용할 수 있다.
- **동시성**은 하나의 작업 내에서 여러 개의 서브 태스크(subtask)를 동시에 처리하는 것을 말한다. 여러 스레드를 생성해 작업을 분할해 처리하거나, 비동기적으로 여러 작업을 처리하는 방식이 있다. 동시성도 동시에 작업을 수행하지만, 작업이 독립적이지 않고 서로 의존성을 가지는 경우에 적합하다.

## Race Condition

참고: https://iredays.tistory.com/125

- 공통 자원에 대한 collision
- 동시에 읽고 사용하는 동작을 하는 경우, 데이터 접근 순서에 따라 실행 결과가 달라지는 상황
- race → 경쟁 상태

관련 개념은 다음과 같다.

- **Mutual Exclusion (상호 배제)**
  - 두 개 이상의 프로세스가 공용 데이터에 접근하는 것을 막아야 한다.
- **Deadlock (교착 상태)**
  - 상호 배제 시행 시 교착 상태가 발생하기도 하는데, 두 자원 모두에 액세스해야 한다고 가정할 때 서로 소유한 리소스를 해제하지 않으면 교착 상태에 빠지게 된다.
- **Starvation (기아 상태)**
  - 더 이상 진행하지 못하고 블록되어 있는 상태. 서로 끝나기를 기다리고 있어 아무것도 완료되지 못하는 상황을 말한다.

## Mutex / Semaphore

Race Condition의 해결 방안이다. 애플리케이션 레벨에서는 다음과 같은 방법을 쓴다.

- Java에서 지원하는 `synchronized` 방법으로 해결하기
- DB가 제공하는 Lock을 이용하여 데이터 정합성 맞추기
- Redis를 활용하여 대표적인 라이브러리 Lettuce와 Redisson으로 해결하기

### Semaphore

- 임계 영역 혹은 데이터에 **여러 객체**가 접근하는 것을 막음 (동기화 대상이 1개 이상)
- 사용하고 있는 스레드와 프로세스의 수를 공통으로 관리하는 값을 이용하여 상호 배제를 달성
- 공유 자원에 접근 가능한 프로세스의 최대 허용치만큼 접근이 가능함
- 비유: 화장실 빈 칸이 몇 개인지 띄워 주는 경우

### Mutex

- 임계 영역 혹은 데이터에 접근을 막는 방식 (동기화 대상이 **1개**)
- Key 기반의 상호 배제 기법
  - key를 가진 객체가 공유 자원에 접근 가능함
  - 뮤텍스 객체는 두 스레드가 동시에 사용할 수 없음
- 비유: 카운터에 키를 빌리러 갔는데 화장실 키가 없는 경우
